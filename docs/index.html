LaraSelector maps any element on your local Laravel page back to the Blade file, page controller or form action behind it, and opens it in your editor.

Install

Requires PHP 8.1+ and Laravel 10, 11 or 12. The service provider is auto-discovered.

composer require --dev mhmdelbadry74/laraselector-laravel
php artisan vendor:publish --tag=laraselector-config

Setup

Enable it in your .env, then clear compiled views.

LARASELECTOR_ENABLED=true
LARASELECTOR_EDITOR=vscode   # vscode | cursor | phpstorm
php artisan view:clear
It only runs in the local and dev environments. Production is always denied, even if enabled.

Usage

  1. Install the Chrome extension and open your local Laravel page.
  2. Open LaraSelector from the toolbar and click Start selecting.
  3. Hover an element and click it, then choose Blade, page controller or form action.
  4. Your editor opens at the exact line. Press Escape to stop selecting.

Chrome extension

Download the ZIP from Releases, unzip it, then open chrome://extensions, turn on Developer mode and choose Load unpacked.

Editors and forms

VS Code and Cursor use vscode://file and cursor://file; PhpStorm uses phpstorm://open. Forms support same-origin relative or absolute actions, GET/POST, _method spoofing and formaction/formmethod on the submit button. Dynamic JavaScript destinations and external origins are not supported.

Security

  • Activation is checked at request and render time, so cached views go inert once disabled.
  • Endpoints return 404 when inactive and require same-origin plus a session token.
  • Routes are matched against a synthetic request and never dispatched.
  • Real paths, symlinks included, must stay inside the allowlist.

Troubleshooting

The extension does not show any marked element

Check that LARASELECTOR_ENABLED=true, that APP_ENV is local or dev, then run php artisan view:clear and reload the page.

The browser says the protocol is not registered (PhpStorm)

Register JetBrains' URL handler or install its command-line launcher on your OS.

The editor opens the wrong path with Docker

Set path_mapping, for example ['/var/www/html' => '/Users/me/project'].

A controller is not found

It must live inside php_inspect_paths (default app/ and routes/). Livewire actions are not supported yet.
