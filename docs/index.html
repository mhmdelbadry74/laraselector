LaraSelector

A development-only Laravel tool: pick a rendered element in Chrome and open its Blade view, page controller or form-action controller in VS Code, Cursor or PhpStorm. You need both the Laravel package and the Chrome extension.

Requirements

  • PHP 8.1+ / Laravel 10, 11, 12
  • LaraSelector Chrome extension
  • VS Code / Cursor / PhpStorm

Installation

composer require --dev mhmdelbadry74/laraselector-laravel
php artisan vendor:publish --tag=laraselector-config

The service provider is auto-discovered.

Configuration

Add to .env:

LARASELECTOR_ENABLED=true
LARASELECTOR_EDITOR=vscode

Then run php artisan view:clear.

Usage

  1. Install the extension and open your local Laravel page.
  2. Open LaraSelector and click Start selecting.
  3. Hover an element, click it, choose Blade / controller / form action. Escape stops.

Chrome extension

Download the release ZIP from Releases, unzip, then chrome://extensions → Developer mode → Load unpacked.

Editors

VS Code/Cursor use vscode://file and cursor://file. PhpStorm uses phpstorm://open; register the JetBrains URL handler if the browser reports an unregistered protocol.

Security

Development only. Activation is checked at request/render time; endpoints return 404 when inactive, require same-origin and a session token, never dispatch routes, and validate real paths (including symlinks) inside the allowlist. Production is always denied.
