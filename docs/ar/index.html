LaraSelector

أداة للتطوير فقط لـ Laravel: اختر أي عنصر في Chrome وافتح مصدره في المحرر: ملف Blade أو الـ Controller الخاص بالصفحة أو الـ form action، في VS Code أو Cursor أو PhpStorm. تحتاج الـ package وإضافة Chrome معًا.

المتطلبات

  • PHP 8.1+ / Laravel 10, 11, 12
  • إضافة LaraSelector لـ Chrome
  • VS Code / Cursor / PhpStorm

التثبيت

composer require --dev mhmdelbadry74/laraselector-laravel
php artisan vendor:publish --tag=laraselector-config

الـ Service Provider يتسجل تلقائيًا.

الإعداد

أضف في .env:

LARASELECTOR_ENABLED=true
LARASELECTOR_EDITOR=vscode

ثم نفّذ php artisan view:clear.

المفتاحالافتراضيالوظيفة
enabledfalseمفتاح التشغيل الرئيسي (LARASELECTOR_ENABLED).
environmentslocal, devالبيئات المسموح بها. production مرفوضة دائمًا.
editorvscodeالمحرر المستخدم: vscode أو cursor أو phpstorm.
application_rootbase_path()الجذر المستخدم للمسارات النسبية.
path_mapping[]ربط المسارات، مثلًا Docker: ['/var/www/html' => '/Users/me/project'].
inspect_pathsresources/viewsمجلدات Blade التي يتم تعليمها.
php_inspect_pathsapp/, routes/مجلدات PHP المسموح فتح الـ controllers منها.
exclude_pathsresources/views/vendorمسارات Blade المستبعدة.
token_ttl_seconds300مدة صلاحية الـ token.

الاستخدام

  1. ثبّت الإضافة وافتح صفحة Laravel المحلية.
  2. افتح LaraSelector واضغط Start selecting.
  3. مرّر على عنصر واضغط عليه واختر Blade أو controller أو form action. Escape للإيقاف.

إضافة Chrome

نزّل ملف ZIP من Releases, وفك الضغط، ثم chrome://extensions ← Developer mode ← Load unpacked.

المحررات

يستخدم VS Code وCursor بروتوكولي vscode://file وcursor://file، وPhpStorm يستخدم phpstorm://open؛ سجّل JetBrains URL handler إذا ظهر بروتوكول غير مسجل.

الأمان

للتطوير فقط. يتم التحقق من التفعيل وقت الطلب/العرض؛ الـ endpoints تُرجع 404 عند عدم التفعيل، وتتطلب same-origin وsession token، ولا تنفّذ الـ routes، وتتحقق من المسارات الحقيقية داخل القائمة المسموحة. بيئة production مرفوضة دائمًا.
