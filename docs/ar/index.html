يربط LaraSelector أي عنصر في صفحة Laravel المحلية بملف Blade أو الـ controller أو الـ form action المسؤول عنه، ويفتحه في محررك.

ابدأ الآنعرض على GitHub
composer require --dev mhmdelbadry74/laraselector-laravel
التثبيتالإعدادالاستخدامإضافة Chromeالخياراتالأمانحل المشاكل
من Blade إلى المحرراضغط على أي عنصر وستصل إلى سطر Blade المقصود، حتى عبر الـ layouts والـ includes والحلقات والـ components.
وللـ Controllers أيضًاافتح الـ controller الخاص بالصفحة أو بالـ form action، سواء كان invokable أو closure.
آمن بطبيعتهللتطوير فقط. بيئة production مرفوضة دائمًا ولا يتم تنفيذ أي route.
محررك المفضليدعم VS Code وCursor وPhpStorm، مع ربط المسارات لـ Docker والبيئات البعيدة.

التثبيت

يتطلب PHP 8.1 أو أحدث وLaravel 10 أو 11 أو 12. الـ Service Provider يتسجل تلقائيًا.

composer require --dev mhmdelbadry74/laraselector-laravel
php artisan vendor:publish --tag=laraselector-config

الإعداد

فعّله في ملف .env ثم امسح الـ views المترجمة.

LARASELECTOR_ENABLED=true
LARASELECTOR_EDITOR=vscode   # vscode | cursor | phpstorm
php artisan view:clear
يعمل فقط في بيئتي local وdev. بيئة production مرفوضة دائمًا حتى لو فعّلته.

الاستخدام

  1. ثبّت إضافة Chrome وافتح صفحة Laravel المحلية.
  2. افتح LaraSelector من شريط الأدوات واضغط Start selecting.
  3. مرّر على أي عنصر واضغط عليه، ثم اختر Blade أو controller الصفحة أو form action.
  4. سيفتح محررك عند السطر المقصود. اضغط Escape لإيقاف التحديد.

إضافة Chrome

نزّل ملف ZIP من Releases، وفك ضغطه، ثم افتح chrome://extensions وفعّل Developer mode واختر Load unpacked.

المحررات والنماذج

يستخدم VS Code وCursor بروتوكولي vscode://file وcursor://file، ويستخدم PhpStorm بروتوكول phpstorm://open. تدعم النماذج الـ actions النسبية والمطلقة من نفس الـ origin، وGET/POST، و_method spoofing، وformaction/formmethod في زر الإرسال. وجهات JavaScript الديناميكية والـ origins الخارجية غير مدعومة.

الأمان

  • يتم فحص التفعيل وقت الطلب والعرض، فتتوقف الـ views المخزنة عن العمل بمجرد التعطيل.
  • الـ endpoints تُرجع 404 عند عدم التفعيل، وتتطلب same-origin وsession token.
  • تتم مطابقة الـ routes على طلب افتراضي ولا يتم تنفيذها أبدًا.
  • يجب أن تبقى المسارات الحقيقية، بما فيها الـ symlinks، داخل القائمة المسموحة.

حل المشاكل

الإضافة لا تُظهر أي عنصر معلَّم

تأكد أن LARASELECTOR_ENABLED=true وأن APP_ENV هي local أو dev، ثم نفّذ php artisan view:clear وأعد تحميل الصفحة.

المتصفح يقول إن البروتوكول غير مسجل (PhpStorm)

سجّل JetBrains URL handler أو ثبّت الـ command-line launcher على نظامك.

المحرر يفتح مسارًا خاطئًا مع Docker

اضبط path_mapping، مثلًا ['/var/www/html' => '/Users/me/project'].

لا يتم العثور على controller

يجب أن يكون داخل php_inspect_paths (الافتراضي app/ وroutes/). إجراءات Livewire غير مدعومة حاليًا.
