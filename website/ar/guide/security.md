# الأمان

LaraSelector للتطوير فقط.

- يتم فحص التفعيل وقت الطلب والعرض، فتتوقف الـ views المخزنة عن العمل بمجرد التعطيل.
- الـ endpoints تُرجع 404 عند عدم التفعيل، وتتطلب same-origin وsession token.
- تتم مطابقة الـ routes على طلب افتراضي ولا يتم تنفيذها أبدًا.
- يجب أن تبقى المسارات الحقيقية، بما فيها الـ symlinks، داخل القائمة المسموحة.
- تعرض الإضافة المسارات النسبية فقط، ولا تفتح المحرر إلا بعد اختيارك لإجراء.
